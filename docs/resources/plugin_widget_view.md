# cycloid_plugin_widget_view (Resource)

Manages the enabled state and URL slug of a plugin widget view in an organization.

For inherited widgets (shared from a parent organization), this creates a local override
without modifying the parent's configuration. This allows child organizations to selectively
enable or disable widgets and customize their URL slugs.

Destroying this resource disables the widget view (sets `enabled = false`).


## Example Usage

```terraform
// Enable a shared plugin's widget view in a child organization.
// The widget view ID can be discovered from the parent plugin's widget views.
resource "cycloid_plugin_widget_view" "enable_dashboard" {
  organization      = "child-org"
  plugin_install_id = 36
  widget_view_id    = 1
  enabled           = true
  url_slug          = "is-management"
}

// Disable an inherited widget view in a child org (creates a local override).
resource "cycloid_plugin_widget_view" "disable_in_child" {
  organization      = "child-org"
  plugin_install_id = 36
  widget_view_id    = 2
  enabled           = false
  url_slug          = "environment-creation"
}
```
