# cycloid_plugin_sharing (Resource)

Manages the sharing configuration of an installed plugin. Controls whether the plugin is visible
to child organizations and which organizations are included or excluded.

When `visibility` is `"shared"`, child organizations inherit the plugin and can enable its
widget views locally. When `"local"`, only the owning organization can see it.

The `mode` attribute controls how the `organizations` list is interpreted:
- `"include"` — only the listed orgs can see the shared plugin (empty list = all children).
- `"exclude"` — all children except the listed orgs can see it.

Destroying this resource resets the plugin to `local` visibility.


## Example Usage

```terraform
// Share a plugin with all child organizations.
resource "cycloid_plugin_sharing" "share_all" {
  organization      = "parent-org"
  plugin_install_id = cycloid_plugin.my_plugin.id
  visibility        = "shared"
  mode              = "include"
}

// Share a plugin only with specific child organizations.
resource "cycloid_plugin_sharing" "share_selected" {
  organization      = "parent-org"
  plugin_install_id = cycloid_plugin.my_plugin.id
  visibility        = "shared"
  mode              = "include"
  organizations     = ["child-org-1", "child-org-2"]
}

// Share with all children except specific organizations.
resource "cycloid_plugin_sharing" "share_except" {
  organization      = "parent-org"
  plugin_install_id = cycloid_plugin.my_plugin.id
  visibility        = "shared"
  mode              = "exclude"
  organizations     = ["excluded-org"]
}
```

## Schema

### Required

- `plugin_install_id` (Number) The ID of the plugin install to configure sharing for.
- `visibility` (String) Sharing visibility: `local` or `shared`.

### Optional

- `mode` (String) Sharing mode: `include` or `exclude`. Defaults to `include`.
- `organization` (String) The organization canonical, defaults to the provider `default_organization`.
- `organizations` (List of String) List of organization canonicals to include or exclude from sharing.
